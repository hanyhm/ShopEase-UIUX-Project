# ShopEase - Modern eCommerce Web Experience

## Project Overview
ShopEase is a UI/UX design project for a modern eCommerce website, focusing on creating an intuitive, responsive, and visually appealing shopping experience.

## Project Duration
October 2025 - 6 Weeks (Agile Scrum Methodology)

## Key Objectives
- Design modern, user-friendly eCommerce interface
- Ensure responsiveness and accessibility
- Simplify checkout flow
- Apply Agile Scrum principles to UI/UX workflow
